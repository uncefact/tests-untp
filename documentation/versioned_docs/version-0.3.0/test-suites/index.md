<Disclaimer />

The UNTP test suite is being refactored. The refactored suite will be distributed
as a Node.js library, for embedding conformance checks into your own tooling, and
as a command-line interface for running them directly. Significant improvements to
the testing infrastructure are planned across subsequent releases.

In the meantime, the [UNTP Playground](https://test.uncefact.org/untp-playground)
offers a test suite you can use today: upload a credential and get immediate
feedback on whether it conforms to the specification.
