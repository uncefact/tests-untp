# UNTP Playground

The UNTP Playground validates UNTP artefacts: verifiable credentials, conformity schemes, and identity-resolver link sets. These pages document behaviour specific to the Playground. They are versioned with the Playground itself, independently of the reference implementation documentation.

Once the loaded artefacts are ready, a report of them and their results can be generated and downloaded; see [Generating reports](./generating-reports.md).
